# Humanoid_D Special Drop Calculator

A client-side React + Vite calculator. It does not use a backend or database.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm test
npm run build
```

## Deploy to Vercel

Import this repository in Vercel. The project uses Vite, builds with `npm run build`, and publishes the `dist` directory. No environment variables are required. The project PDF is served from `public/` and included in the deployment.
